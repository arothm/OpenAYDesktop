Usage & context
The most a chat sends with each request. Past it, older messages are replaced by a summary the model writes (your own messages stay, shortened), kept until the next one. Full (recommended) summarizes only when the model's window is nearly full: Ollama bills the unchanged start of a conversation at its much cheaper cached-input rate, so resending history costs little. Economy and Balanced send fewer tokens per request and suit models without cached-input pricing or very long chats.
–
Token limits count tokens sent and generated, as Ollama reports them; 0 turns a limit off. When a limit is reached, replies stop with a message until you raise it. Subtasks count toward every limit. When your Ollama balance is at or below the pause amount, running replies summarize their progress and pause, then continue by themselves once you recharge.
Memory
Notes every chat can use, one per line. Chats with Memory on add notes when you ask them to remember something, and you can edit them here. A chat that has read web content asks you before saving. Projects have their own memory too.
Allowed commands
One per line. A command runs without asking only if it matches exactly; end a line with  * to allow extra arguments. Only chats with "Run commands" turned on can use them.
